═══════════════════════════════════════════════════════════════
  MPV как анимированные обои — установка и автозапуск (Windows)
═══════════════════════════════════════════════════════════════

┌─ 1. СКАЧАТЬ И УСТАНОВИТЬ MPV (без winget) ─────────────────┐
│                                                            │
│  1. Открой в браузере:                                     │
│     https://github.com/shinchiro/mpv-winbuild-cmake/releases│
│                                                            │
│  2. Скачай файл для 64-бит Windows:                         │
│     mpv-x86_64-*-git-*.7z  ИЛИ  mpv-dev-x86_64-*-git-*.7z   │
│     (название с последней датой)                             │
│                                                            │
│  3. Создай папку  C:\mpv\                                  │
│                                                            │
│  4. Распакуй архив 7z:                                      │
│     Установи 7-Zip (7-zip.org) если нет.                    │
│     ПКМ по .7z - 7-Zip - Extract to "папка\"                 │
│     Открой распакованную папку.                             │
│     Скопируй ВСЁ (mpv.exe, *.dll) в C:\mpv\                 │
│     Итог: C:\mpv\mpv.exe существует                         │
│                                                            │
│  5. Запусти run_mpv_wallpaper.bat                          │
│                                                            │
└────────────────────────────────────────────────────────────┘

┌─ 2. ЗАПУСК MPV КАК ОБОИ ──────────────────────────────────┐
│                                                            │
│  А) Один файл или плейлист:                                │
│     mpv --loop --fullscreen --player-operation-mode=pseudo-gui video.mp4
│                                                            │
│  Б) Плейлист (слайд-шоу GIF/видео):                        │
│     mpv --loop --fullscreen --player-operation-mode=pseudo-gui playlist.m3u
│                                                            │
│  Полезные опции:                                           │
│  --ontop           окно поверх всех (видео всегда видно)   │
│  --no-ontop        под окнами приложений (по умолчанию)    │
│  --loop=inf        бесконечный цикл                        │
│  --video-margin-ratio=0  без чёрных полей                  │
│                                                            │
└────────────────────────────────────────────────────────────┘

┌─ 3. АВТОЗАПУСК ПРИ ВХОДЕ В WINDOWS ───────────────────────┐
│                                                            │
│  1. Нажми Win+R, введи: shell:startup                      │
│  2. Enter — откроется папка автозагрузки                   │
│  3. Создай ярлык (.lnk) на run_mpv_wallpaper.bat           │
│     Или скопируй run_mpv_wallpaper.bat в эту папку         │
│  4. При следующей загрузке Windows MPV запустится сам       │
│                                                            │
│  Чтобы отключить — удали ярлык/файл из папки автозагрузки  │
│                                                            │
└────────────────────────────────────────────────────────────┘

┌─ 4. СОЗДАНИЕ ПЛЕЙЛИСТА ───────────────────────────────────┐
│                                                            │
│  Файл playlist.m3u — простой текст:                        │
│  #EXTM3U                                                    │
│  C:\путь\video1.mp4                                         │
│  C:\путь\gif1.gif                                           │
│  C:\путь\video2.webm                                        │
│                                                            │
│  Скрипт make_playlist.bat создаёт плейлист из папки.       │
│                                                            │
└────────────────────────────────────────────────────────────┘
