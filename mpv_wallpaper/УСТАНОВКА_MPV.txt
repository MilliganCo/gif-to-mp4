  MPV — установка без winget (пошагово)
═══════════════════════════════════════════════

У тебя нет winget — устанавливаем вручную:

┌─────────────────────────────────────────────┐
│ 1. Скачать MPV                              │
└─────────────────────────────────────────────┘

   Перейди по ссылке:
   https://github.com/shinchiro/mpv-winbuild-cmake/releases

   Скачай файл для 64-бит Windows (один из):
   • mpv-x86_64-20260302-git-af9c81f.7z
   • mpv-dev-x86_64-20260302-git-af9c81f.7z

   (Если видишь новее — бери последний по дате)

┌─────────────────────────────────────────────┐
│ 2. Распаковать                              │
└─────────────────────────────────────────────┘

   • Установи 7-Zip с 7-zip.org (если нет)
   • Правый клик по .7z → 7-Zip → Распаковать
   • Выбери папку C:\mpv\ (создай её заранее)

   ИЛИ: распакуй куда угодно, потом скопируй
   содержимое (mpv.exe и все .dll) в C:\mpv\

┌─────────────────────────────────────────────┐
│ 3. Проверить                               │
└─────────────────────────────────────────────┘

   Должен быть файл:  C:\mpv\mpv.exe

   Запусти run_mpv_wallpaper.bat — теперь
   скрипт найдёт MPV автоматически.
