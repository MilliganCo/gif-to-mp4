# GIF To MP4

> Public experimental source: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known defects, restored modules and operational limits. Earlier audit decisions are historical.

## Описание

Локальная Python-утилита для массовой конвертации GIF в форматы, удобные для использования в Wallpaper Engine: `MP4`, `WebM` и оптимизированный `GIF` в 1080p.

Проект решает практическую задачу подготовки анимированных файлов под desktop wallpaper-сценарии. Внутри есть не только основной конвертер, но и вспомогательные скрипты для проверки и сравнения получившихся MP4 через `ffprobe`.

## Возможности

- пакетная конвертация GIF в `MP4`;
- альтернативная конвертация в `WebM`;
- пересборка GIF в 1080p и 60 FPS;
- автоматическое продление слишком коротких роликов;
- отдельный режим для повторной обработки уже готовых `MP4`;
- вспомогательные проверки результата через `ffprobe`.

## Стек

- Python
- Tkinter
- `ffmpeg`
- `ffprobe`
- `tqdm`

## Как использовать

1. Установите `ffmpeg` и `ffprobe` в систему.
2. Запустите `gif_to_mp4.py`.
3. Выберите папку с GIF-файлами.
4. При необходимости используйте режимы `fix`, `copy`, `webm` или `gif1080`.
